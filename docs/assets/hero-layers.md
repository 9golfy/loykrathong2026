# Hero scene layers

The homepage uses independent DOM layers rather than one animated background image.

## Current compositing order

1. CSS navy sky (the supplied photo sky is removed).
2. Photographic Wat Arun skyline, static: `public/images/hero-layers/wat-arun-skyline-photo.png`.
3. Photographic river plate: `public/images/hero-layers/wat-arun-water-photo.png`, animated as 20 horizontal strips. Temple pixels never enter these strips.
4. Transparent fireworks: `public/images/hero-layers/firework.png`; four independently timed launch/bloom/fade cycles.
5. Transparent Yi Peng lantern: `public/images/hero-layers/lantern.png`; five independently timed upward drifts.
6. Public krathongs: left-to-right horizontal movement, constant size, behind the dock and people. Desktop artwork is 280x240px (formerly 140x120); mobile is 220x200px (formerly 110x100).
7. Connected pavilion, dock, couple and held krathong: `public/images/hero-layers/foreground-pavilion-couple-held.png` (1448x1086 RGBA). The woman supports a small krathong with both hands, rendered into this single static asset. Desktop retains the latest reduced foreground size; mobile scales the same complete image.
8. The separate hand-side krathong element, positioning and bob/ripple animation have been removed. `krathong.png` remains available as a reusable asset.
9. HTML title and controls.

The pause control pauses water, fireworks, lanterns and moving public krathongs. The couple and held krathong are static. Reduced-motion disables animation. Artwork is decorative and has no pointer events.

Photographic source supplied by the user: `LINE_ALBUM_รูปลอยกระทง กรมส่งเสริม_261107_2.jpg` (1280x854). The photo layers retain this source coordinate system, with the bank at approximately 69.1% of the source height. The extracted PNGs are 1535x1024; both use the same normalized 1280x854 source coordinate system and projected scene coordinates.

Original illustrated reference supplied by the user: `exec-fc2fb047-d5ed-42f8-a598-eb767c089e34.png`. The transparent pavilion/couple, lotus krathong, fireworks and lantern assets match this reference. `couple.png` is an earlier standalone couple extraction retained for reuse. `temple-river.png` is the earlier clean illustrated background plate.

All raster extractions/edits used the built-in imagegen tool, with genuine alpha preserved. No CLI or hand-written raster processing was used. Python/Pillow was used only to inspect dimensions and alpha metadata.
