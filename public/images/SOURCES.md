## Current panorama

`temple-night-scene.png`: original user-provided image `codex-clipboard-d1b04d79-c154-4f76-9dba-388089a43ca6.png`, copied without raster edits. Current homepage background.

The original lower portion contains a baked-in checkerboard. `components/water-scene.tsx` and CSS display the upper scene above its 62.8% bank, reconstruct a mirrored reflection with 32 horizontal CSS background bands, and animate only those bands and water highlights. No generated image, canvas, SVG filters, video or JavaScript animation is used. Reduced-motion disables the effect.
